# Шаг

Спокойный планировщик целей для Android 11 и новее. Разбивайте большие планы на небольшие шаги, храните текст, фотографии, документы и аудиозаметки рядом с целью.

**[Скачать APK](https://github.com/lisowsky146-beep/shag/releases/latest/download/Shag.apk)** · [Все версии](https://github.com/lisowsky146-beep/shag/releases) · [Сообщить об ошибке](https://github.com/lisowsky146-beep/shag/issues)

Приложение находится на этапе пользовательского тестирования.

## Возможности

- Цели с обложками и приоритетами; шаги можно выполнять в любом порядке.
- Фото, видео, документы и аудио внутри шагов.
- Локальное распознавание русского аудио и текста с изображений.
- Сроки, напоминания и перенос дедлайна.
- Секретные цели с системной проверкой отпечатка или блокировки телефона.
- Обмен обычной целью через файл и резервное копирование.
- Дизайн блокнота, мягкие цвета и тихий мини-салют после завершения.

Без регистрации, рекламы и облачного хранения. Модели распознавания включены в APK, компактная версия ARM64 занимает 74,2 МБ, универсальная — 191,4 МБ.

## Установка и обновление

1. Скачайте один подходящий APK из таблицы ниже. Если не знаете архитектуру, выберите универсальный.
2. Откройте файл на телефоне. Если Android попросит, разрешите установку из используемого браузера или файлового менеджера.
3. Для обновления установите новую версию поверх старой. **Не удаляйте приложение:** при удалении будут потеряны локальные данные, включая секретные цели.

Автоматической установки обновлений пока нет. Новые версии публикуются в Releases. Для обычных целей доступна резервная копия; секретные цели в неё не входят.

## Вложения

Нажатие на скрепку открывает панель вложений, удержание начинает запись аудио. Встроенная сетка фотографий доступна при поддержке системного Embedded Photo Picker; на остальных устройствах используется системный выбор файлов. Приложение не запрашивает доступ ко всей медиатеке.
